# تركي — الموقع الشخصي

موقع ثابت (HTML/CSS/JS) بلا خطوة بناء. يفتح مباشرة من `index.html`، ويُفضّل تشغيله عبر خادم محلي حتى تعمل الخطوط والصور كما ينبغي:

```bash
python3 -m http.server 4188
# http://127.0.0.1:4188/
```

## البنية

- `index.html` — الصفحة، والنصوص العربية هي الأصل.
- `styles.css` — نظام التصميم، اللوحة، الدوك، والتجاوب.
- `app.js` — الترجمة الإنجليزية، الساعة، تبديل العمل النشط عند التمرير، واللغة.
- `progress.html` — لوحة متابعة المهام والحالة، محلية وتحفظ في `localStorage`.
- `assets/projects/` — صور الأعمال. `screen-*.jpg` للوحة العرض، و`*.jpg` للجوال.
- `assets/icons/` — أيقونات الأعمال في الدوك.
- `assets/fonts/` — Thmanyah Serif Display وEl Messiri، و`amiri-verse.woff2` (خط Amiri مقتطع لبيت المتنبي فقط، رخصة OFL).
- `assets/landscape/` — اللوحة وطبقاتها ومحرّك Three.js المحلي. يربط `landscape-scroll.js` ضوء المشهد بتمرير المقدمة، ويضبط `landscape.css` ألوان الغروب والشفق وتباين النص فوق الخلفية الليلية.
- `assets/og.jpg` — صورة المشاركة 1200×630 (og:image).

## تعديل المحتوى

النص العربي داخل `index.html`، ويُربط بمفتاح عبر `data-i18n="..."`. الترجمة الإنجليزية في كائن `EN` داخل `app.js`، ويجب أن تستخدم المفتاح نفسه.

- **الأعمال:** لكل عمل قسم `<section class="project" data-project="N" id="p-...">`، وترتيبها هو ترتيب التمرير والدوك.
- **روابط الأعمال:** في `index.html` (زر «افتح» ورابط النطاق)، وفي مصفوفة `PROJECTS` داخل `app.js` (تحدّث تبويب النافذة عند التمرير).
- **الحسابات:** روابط GitHub وX في أعلى الصفحة وفي التذييل داخل `index.html`.
- **اللغة الافتراضية:** العربية. الاختيار يُحفظ في `localStorage` تحت `lang`.

## لوحة المتابعة

افتح `progress.html` من المتصفح أو عبر الخادم المحلي. المهام والحالات معرّفة في `TASKS` داخل الصفحة:

- اضغط حالة أي مهمة لتبديلها: منجز ← التالي ← قيد التنفيذ ← منجز.
- الحالة تُحفظ محليًا تحت `turki-progress-v1`.
- «إعادة الضبط» ترجع الحالات الافتراضية وتمسح الحفظ المحلي.
- شريط التقدم، وملخص «الآن»، وقائمة «التالي» تتحدّث تلقائيًا.

## الصور والخطوط

- صور لوحة العرض مقاس 1280×1422، وتُقص من الأعلى داخل اللوحة.
- لاستبدال صورة: استخدم `assets/projects/screen-<name>.jpg` بالمقاس نفسه، وحدّث المسار في `index.html`.
- الخطوط محلية؛ راجع ملفاتها في `assets/fonts/` للترخيص قبل إعادة التوزيع.
- رخصة Three.js مرفقة في `assets/landscape/three-LICENSE.txt`.
